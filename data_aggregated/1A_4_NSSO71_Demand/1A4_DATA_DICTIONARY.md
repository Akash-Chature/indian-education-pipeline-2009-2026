# Stage 1A.4 Data Dictionary — NSSO 71st Round (Schedule 25.2, Jan–Jun 2014)

**Release Gate:** **CLEARED FOR PUBLIC GITHUB RELEASE** (`12` hardened demand-side summary CSVs; `0` float noise, `0` duplicates, `0` SQL placeholder headers).

### Global Methodological Conventions
- **Survey Weights:** Every mean, share, and quintile is weighted strictly by `wgt_combined` (never unweighted averages). Raw sample counts (`n_unweighted`, `n_hh`, `n_students`) are always paired beside weighted totals.
- **Sector-Specific UMPCE Quintiles (`sector_umpce_quintile`):** `Q1 (Poorest)` through `Q5 (Richest)` are computed separately inside `Rural` and inside `Urban` (exact 20.0% population shares each) so urban price levels do not distort poverty tiers.
- **Thin-Cell Gate (`low_n_flag`):** `low_n_flag = 1` flags any cell with unweighted sample size `< 30`. Inside `1A4_nss_region_and_district_diagnostic_scorecard.csv`, domain metrics with `n < 30` are masked to `NULL` and excluded from District Stress Rankings.
- **Critical Raw-Data Notes:** (1) `hostel_exp` in Block 6 holds the **Hostel Destination State/UT code (`1–35`)**, not rupees, and is excluded from rupee wallet totals; (2) `nature_inst` (`Recognized`/`Unrecognized`) was canvassed strictly for `General + Private Unaided` students in Schedule 25.2 (dual denominators reported in Deliverable 9).
